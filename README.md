I dette projekt tager vi udgangspunkt i Midttrafik live appen. Vi har brugt appen som grundlag for et redesign i forbindelse med eksamen i dynamic user interface på 3. semester af multimediedesign uddannelsen.

Opgaven var at implementere mindeværdigt design til et allerede eksisterende og mindeværdigt produkt.

**Datakilder og licens**

Denne applikation anvender GTFS-køreplansdata fra Rejsekort & Rejseplan A/S, distribueret via Mobility Database.

Dataene er licenseret under [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
