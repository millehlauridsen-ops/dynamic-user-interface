# Projektbeskrivelse

## Navn
Fælles React-arbejdsrum (midlertidigt navn).

## Formål
Kørbar frontend-startpakke, som kan danne udgangspunkt for en egentlig app. Den medfølgende demo viser projektkort, navigation og statusændringer.

## Produktmål
**Udfyldes af teamet:** Hvem er appen til? Hvilket problem løser den? Hvad er MVP'en?

## Ikke inkluderet endnu
Login, adgangsstyring, fælles database, server/API, deployment og testsuite.
