# Start her

Denne ZIP indeholder **både fungerende React-kode og dokumentation**.

## Til et helt nyt repository
1. Pak ZIP'en ud og flyt indholdet til roden af repoet.
2. Kør `npm install` og `npm run dev`.
3. Besøg appen og prøv at oprette et projekt.
4. Erstat demoindhold med jeres eget produkt.
5. Commit og push til GitHub.

## Til et eksisterende repository
1. Opret en ny branch.
2. Sammenlign først `package.json`, `src/` og `vite.config.js` med jeres kode.
3. Kopiér kun de ønskede filer; overskriv ikke eksisterende kode blindt.
4. Læg `AGENTS.md` og `docs/` ved roden.
5. Test før merge.

## Til fælles ChatGPT
Kopiér indholdet af `CHATGPT_PROJECT_INSTRUCTIONS.md` ind i jeres fælles projekts instruktioner og indsæt jeres GitHub-repo-URL.

**Bemærk:** Appens lokale projekter deles ikke mellem personer. Det kræver backend og database.
