# Samarbejdsworkflow

1. Opret en issue eller beskriv opgaven og den forventede adfærd.
2. Arbejd på egen branch (`feature/…`, `fix/…`).
3. Bed Codex om at læse `AGENTS.md` og relevante `docs/`-filer.
4. Implementér ændringen i de eksisterende mapper.
5. Kør `npm run check` og `npm run build`.
6. Opdatér beslutninger og arkitektur, hvis de ændres.
7. Opret pull request, få review fra den anden udvikler, og merge.

Projektinstruktioner i ChatGPT og `AGENTS.md` er forskellige ting. Opdatér begge ved større ændringer til udviklingsprincipperne.
