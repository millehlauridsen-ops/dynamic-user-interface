# React-template

Tomt React-projekt med JavaScript, Vite og React Router.

```bash
npm install
npm run dev
```

Produktionsbuild: `npm run build`.

Ruter defineres i `src/App.jsx`. `BrowserRouter` ligger i `src/main.jsx`.
Forsiden returnerer `null`, og `src/globals.css` er tom.

Mapperne `src/components/`, `src/hooks/`, `src/services/`, `src/lib/`,
`src/assets/` og `public/` er klar til brug. `.gitkeep` bevarer tomme mapper i Git.
